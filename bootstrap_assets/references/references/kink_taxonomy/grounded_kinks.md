## Use Rules
- Pick only preferences that fit the emotional tone and compatibility with the source character.
- Keep the list grounded, modern, and human.
- Favor preferences that reinforce chemistry rather than novelty for novelty's sake.
- If the route is soft, exclusive, or romantic-first, prefer gentler and more intimate preferences.
- If the route is protective, possessive, or dominant, choose complementary preferences rather than random escalation.
- Usually 5 to 8 preferences is enough unless the prompt explicitly asks for more.
- If a preference needs a very specific dynamic to work, only use it when the source character and route clearly support that dynamic.
- If the output reads like a copied fetish bundle rather than a fitted preference profile, trim and rewrite it.
