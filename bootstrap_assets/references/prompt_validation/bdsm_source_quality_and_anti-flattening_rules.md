# BDSM Source Quality And Anti-Flattening Rules

## Purpose
This reference distills the strongest validation logic from:
- grounded BDSM qualitative and practitioner sources already routed into CharacterGen
- repeated anti-`fake dom` warnings from practitioner spaces
- the standing CharacterGen requirement that intimacy logic stay consent-forward, behavior-rich, and psychologically human

Use it as an internal source-hygiene and failure-mode note for CharacterGen when:
- promoting BDSM or D/s material into active references
- writing `Scenario`
- writing `First Message Examples`
- drafting intimate dialogue
- evaluating whether a source adds real value or just scene decoration

It is not a sex-tip source.
It is a filtering and calibration source.

## Non-Verbatim Rule
This file is for evaluation and filtering, not output copy.

Use it to:
- reject weak source logic
- catch flattening
- steer revisions

Do not surface its rule language verbatim in generated scenes or character text.

## Core Rule
Do not reward aesthetics without relationship logic.

Good BDSM-adjacent source material explains:
- why the dynamic matters
- how consent is negotiated
- what each role is attending to
- how trust is built, stressed, and repaired
- what care looks like before, during, and after intensity

Weak source material only offers:
- labels
- positions
- scripts
- insults
- costume logic
- pornified posture without emotional mechanics

## Promotion Standard
Promote a BDSM-related source only if it materially improves at least one of:
- motivation
- trust logic
- negotiation logic
- safety logic
- repair logic
- role-specific attention patterns
- body or behavior under pressure

If a source cannot improve one of those, it should usually stay out of the active stack.

## Green Flags In A Source

### 1. Consent Is Built, Not Assumed
Useful sources show:
- negotiation before intensity
- explicit boundaries or limits
- safewords or other stop/change mechanisms
- ongoing check-ins
- the submissive's ability to alter or stop the scene

Practical rule:
- the submission should read as chosen, not extracted

### 2. Dominance Includes Care And Responsibility
Useful sources frame dominance as:
- attentiveness
- steadiness
- responsibility
- follow-through
- restraint
- partner monitoring

Good dominant material usually includes:
- empathy
- self-control
- accountability
- aftercare
- awareness that power is granted, not taken

### 3. Submission Includes Agency
Useful sources frame submission as:
- chosen surrender
- trust
- relief
- vulnerability with structure
- psychological or sensory meaning

Good submissive material does not erase:
- personality
- boundaries
- motives
- self-knowledge
- the ability to speak, refuse, redirect, or re-approach

### 4. Aftercare And Landing Matter
Useful sources treat the end of a scene as part of the scene.

Look for:
- reassurance
- decompression
- water, warmth, touch, quiet, or grounding
- discussion of what worked or did not
- signs that both partners may need care, not only the submissive

### 5. The Dynamic Changes Emotional Reality
Useful sources treat intimacy as something that changes:
- trust
- fear
- shame
- attachment
- vulnerability
- role confidence

If the source treats the scene like a mechanical sex act, it is usually too thin.

## Red Flags In A Source

### 1. Cartoon Dominance
Reject sources that flatten dominance into:
- constant shouting
- random cruelty
- humiliation without trust logic
- unprovoked degradation
- possessiveness without responsibility
- swagger standing in for competence

Practical rule:
- if a source treats intimidation as proof of skill, it is probably weak

### 2. Submission As Emptiness
Reject sources that flatten submission into:
- passivity without motive
- obedience without interiority
- weakness as the whole personality
- helplessness presented as the same thing as surrender

Submission should still contain:
- preference
- discernment
- emotional logic
- chosen participation

### 3. Abuse Logic Dressed As BDSM
Reject sources that confuse BDSM with:
- coercion
- lack of negotiation
- unilateral rulemaking
- punishment without consent framework
- emotional destabilization as a virtue
- isolating or belittling a partner outside negotiated play

### 4. Porn-Script Logic
Reject sources that depend on:
- stock insults
- generic dirty talk lists
- technique bragging without emotional context
- instant intensity without trust or buildup
- commands that ignore partner state

These sources may provide occasional act vocabulary, but they should not shape CharacterGen behavior.

### 5. Ideological Or Essentialist Claims
Reject sources that argue:
- one gender is naturally meant to dominate or submit
- biology proves superiority or inferiority
- women's submission is evidence of their proper place
- cruelty is spiritually or morally elevating by default

These are especially dangerous because they mimic explanation while actually collapsing complexity.

## Common Weak Source Types
- generic sex-tip PDFs
- storefront content built mainly to sell toys or memberships
- social-media slides with no context
- domination advice built around ego performance
- humiliation guides without consent or repair logic
- giant fantasy lists with no interpretation
- dirty-talk dictionaries
- technique manuals that ignore trust, pacing, and aftermath

These sources are not automatically useless, but they should almost never become active references untouched.

## How CharacterGen Should Rewrite Weak Material

### If the source gives commands
Rewrite into:
- negotiation logic
- pacing logic
- role motive
- emotional effect

### If the source gives archetypes
Rewrite into:
- attention pattern
- support preference
- stress behavior
- consent posture
- attachment interaction

### If the source gives kinks or acts
Rewrite into:
- what the act means to the character
- what trust it requires
- what it changes emotionally
- what care or repair it implies

## Practical Generation Rules

### For `Scenario`
Do not frame BDSM dynamics as:
- ambient cruelty
- vibe-only dominance
- automatic submission without relationship logic

Instead, make the setup show:
- trust pressure
- negotiation pressure
- reputation pressure
- vulnerability
- care before intensity

### For `First Message Examples`
Do not use:
- stock insults
- generic pet names without context
- one-note orders
- fake-alpha bravado

Prefer:
- attentive control
- measured invitation
- grounding language
- explicit or implied check-ins
- personality-specific power expression

### For intimate dialogue
Ask:
- who is monitoring whom
- who is asking
- who is reassuring
- who is taking responsibility
- who is deciding to yield, and why

## Quick Triage Questions
Before promoting a source, ask:
1. Does this source explain why the behavior matters emotionally?
2. Does it preserve submissive agency?
3. Does it portray dominance as responsibility rather than entitlement?
4. Does it distinguish consensual structure from abuse?
5. Does it include repair, landing, or aftermath logic?
6. Would using this source make CharacterGen more human, or just more performative?

If the answer to most of these is no, quarantine the source.

## CharacterGen Takeaway
Strong BDSM material for CharacterGen should produce:
- better care
- better consent
- better motive clarity
- better role differentiation
- better repair
- less cartoon power

The target is not "hotter by default."
The target is more believable, more grounded, and more emotionally legible.
